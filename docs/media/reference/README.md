핵심 관찰(2026-07-18 phase 9 근거):
- 다시마 숲: 한 홀드패스트에서 여러 가닥이 나오는 **다발 군락**이 좌우를 채움, 중앙만 통로. 먼 열은 흐릿(원근 레이어). 톤은 황금-올리브.
- 산호초: **솟은 리프 마운드 표면을 수십 개 콜로니가 뒤덮음**(맨모래에 드문드문 X). 주역은 분홍/마젠타 뭉게(nub) 마운드형. 모래는 리프 주변 채널.
